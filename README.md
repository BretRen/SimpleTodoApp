# Simple Todo App
This is a practice project created during the Terra preparation week. It might not see many updates, though I do use it myself :D

Demo: https://simpletodoapp.pages.dev/

Develop:

```bash
# You need have node (>=24) and pnpm (>=11)
git clone https://github.com/bretren/simpletodoapp
cd simpletodoapp
pnpm i
pnpm dev
```
